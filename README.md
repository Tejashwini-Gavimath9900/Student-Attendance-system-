
# 🎓 Student Attendance Management System

A simple Python-based Student Attendance Management System that helps manage student details and attendance records using CSV file handling.

## 🚀 Features

- Add new students with Name and USN.
- Mark students as Present or Absent.
- View student attendance records.
- Store records permanently using CSV files.
- Simple menu-driven interface.

## 🛠️ Technologies Used

- Python
- CSV Module
- OS Module

## 📂 Project Structure

Student-Attendance-System/
│
├── attendance.py
├── attendance.csv
└── README.md

## ⚙️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python attendance.py
```

## 📸 Output

The program displays a menu with four options:

1. Add Student
2. Mark Attendance
3. View Attendance
4. Exit
